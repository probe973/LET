# LET Attendance Dashboard Guide

Welcome to the user guide for the **LET Attendance Dashboard**, version 4.0.0.

This guide explains how to open the app, enter and review attendance information, maintain course and topic lists, and explore attendance analysis.

> **Illustrations:** Images of data tables in this guide are recreated mock-ups using fictional example values. They are not screenshots of live records.

## Choose a task

- [Getting started](getting-started.html) — open the dashboard from Microsoft Teams.
- [Home screen](home-screen.html) — understand the summary banner, navigation and attendance overview.
- [Drop-ins](drop-ins.html) — enter and save attendance for drop-in events.
- [Retreats](retreats.html) — record attendance for single or multiple courses and levels.
- [Workshops](workshops.html) — add, find, edit and delete workshop records.
- [Tools](tools.html) — manage course and topic lists and review application status.
- [Analysis](analysis.html) — explore attendance by event type, academic year, school or level.
